# Sultan-bahadur-tech-
Build a multi-restaurant POS SaaS named Sultan Bahadur Tech, founded by Okasha Awan (Founder &amp; CEO). Use Next.js, Supabase and Vercel. Include secure login, Super Admin, restaurant accounts, multi-branch support, POS, menu editing, pizza Small/Medium/Large pricing, orders, payments, kitchen display, receipts, reports, subscriptions
